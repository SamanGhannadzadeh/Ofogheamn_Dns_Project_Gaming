# آیفون / آیپد

## پروفایل DoH آماده: `OfoghDns.mobileconfig`

این پروفایل دو چیز نصب می‌کند:

۱. تنظیم DNS رمزنگاری‌شده (DoH) به `https://dns.ofogheamn.ir/dns-query`
۲. گواهی CA خود نود، تا آیفون به گواهی خودامضای نود اعتماد کند

نصب: فایل را در آیفون باز کنید ← Settings ← Profile Downloaded ← Install.

**پیش‌شرط:** نام `dns.ofogheamn.ir` باید در DNS عمومی به IP نود اشاره کند
(به ماتریس `../README.md` نگاه کنید)؛ تا آن روز پروفایل نصب می‌شود ولی
چون نام سرور پیدا نمی‌شود، DNS رمزنگاری‌شده فعال نمی‌شود.

## مسیر آماده (امروز)

- روی وای‌فای خانه: Settings ← Wi-Fi ← شبکهٔ خودتان ← Configure DNS:
  Manual ← `180.149.45.237` در هر دو خانه.
- یا برنامهٔ sing-box iOS با کانفیگ نردبان پروژه (DNS از داخل تونل).
