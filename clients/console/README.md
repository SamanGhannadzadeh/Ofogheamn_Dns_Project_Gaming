# تنظیم DNS کنسول‌ها

مقادیر برای همهٔ کنسول‌ها یکی است:

- **Primary DNS:** `180.149.45.237`
- **Secondary DNS:** `180.149.45.237` (حتماً هر دو خانه همین IP؛ خانهٔ دوم را خالی یا 8.8.8.8 نگذارید، وگرنه کنسول گاهی از مسیر دوم می‌رود و بهینه‌سازی نود را از دست می‌دهید)
- **Proxy Server:** استفاده نشود (Do Not Use)
- **MTU:** خودکار

## پلی‌استیشن ۵

Settings ← Network ← Settings ← Set Up Internet Connection ← شبکهٔ خودتان ←
Advanced Settings ← DNS Settings: Manual ← مقادیر بالا ← OK و تست اتصال.

## ایکس‌باکس

Settings ← General ← Network settings ← Advanced settings ←
DNS settings: Manual ← مقادیر بالا.

## نینتندو سوییچ

System Settings ← Internet ← Internet Settings ← شبکهٔ خودتان ←
Change Settings ← DNS Settings: Manual ← مقادیر بالا.
