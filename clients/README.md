نود: `180.149.45.237` — DNS روی UDP/TCP پورت ۵۳، ‏DoT روی ۸۵۳، ‏DoH روی
`https://dns.ofogheamn.ir/dns-query`

| پلتفرم | روش | وضعیت |
|---|---|---|
| پلی‌استیشن / ایکس‌باکس / سوییچ | DNS دستی = IP نود (هر دو خانه) | ✅ آماده |

| لینوکس | دراپ‌این systemd-resolved در `linux/` (+ DoT با CA نود) | ✅ آماده |

## «فعال‌سازی دامنه» یعنی چه؟

نام `dns.ofogheamn.ir` هنوز در DNS عمومی ثبت نشده و گواهی TLS نود خودامضاست.
به محض اینکه رکورد زیر ساخته شود:

```
dns.ofogheamn.ir.  A  180.149.45.237
```

گواهی معتبر عمومی (Let's Encrypt) به‌صورت خودکار جایگزین می‌شود و مسیرهای
رمزنگاری‌شدهٔ اندروید (Private DNS)، آیفون (پروفایل DoH) و ویندوز (DoH)
بدون هیچ تغییری در کلاینت‌ها فعال می‌شوند. تا آن روز، مسیرهای «آماده» در
جدول بالا مسیر رسمی هر پلتفرم‌اند.

## پوشه‌ها

- `console/` — تنظیم کنسول‌ها قدم‌به‌قدم
- `windows/` — اسکریپت تنظیم DNS ویندوز (با سوییچ بازگشت به DHCP)
- `android/` — راهنمای اندروید: برنامهٔ sing-box و Private DNS
- `ios/` — پروفایل DoH آیفون + راهنما
- `linux/` — دراپ‌این resolved، گواهی CA نود و راهنمای DoT
