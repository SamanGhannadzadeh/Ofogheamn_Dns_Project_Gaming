# نود افق امن روی مک — macOS server node

هستهٔ SmartDNS نسخهٔ مک ندارد؛ روی مک همان مدل با هستهٔ بومی **AdGuard Home** اجرا می‌شود: مسابقهٔ موازی آپ‌استریم‌ها و برد سریع‌ترین جواب، کش بزرگ با serve-stale، هایجک (Rewrites)، لیست مسدودسازی و محدودیت نرخ. پروکسی sing-box هم بومی است (Apple Silicon و Intel).

## نصب

```bash
bash platforms/macos/install.sh
```

- پنل مدیریت DNS: ‏`http://localhost:3000` (اولین ورود: ساخت کاربر مدیر)
- DNS روی IP همین مک: پورت 53 (UDP و TCP). ‏DoT/DoH به‌صورت پیش‌فرض سرو نمی‌شود؛ از پنل AdGuard Home در Settings ← Encryption با یک گواهی می‌توانی روشنش کنی.
- پروکسی: پورت 2080 با کاربر `ofogh` (رمز در خروجی نصب و در `/usr/local/etc/ofogheamn/proxy.json`)
- حذف: `bash platforms/macos/uninstall.sh`

## تفاوت با نسخهٔ لینوکس (صادقانه)

- پنل مدیریت فارسی افق امن و تونل سروری WireGuard با NAT فعلاً نسخهٔ لینوکسی‌اند؛ روی مک داشبورد AdGuard Home مدیریت DNS را می‌دهد و برای تونل کلاینت، اپ رسمی WireGuard کانفیگ‌های نودها را می‌گیرد.
- مش (اتصال نودها) روی مک در حالت اندازه‌گیری و گزارش کار می‌کند؛ زنجیره‌کردن خروجی فعلاً لینوکسی است.
