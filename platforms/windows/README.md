# نود افق امن روی ویندوز — Windows server node

هستهٔ SmartDNS نسخهٔ ویندوز ندارد؛ روی ویندوز همان مدل با هستهٔ بومی **AdGuard Home** اجرا می‌شود: همهٔ آپ‌استریم‌ها موازی مسابقه می‌دهند و سریع‌ترین جواب برنده است، کش بزرگ با serve-stale، هایجک (Rewrites)، لیست مسدودسازی و محدودیت نرخ — همان رفتار نسخهٔ لینوکس، با باینری بومی ویندوز. پروکسی sing-box هم بومی است.

## نصب

PowerShell را «Run as Administrator» باز کنید:

```powershell
cd <repo>\platforms\windows
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

- پنل مدیریت DNS: ‏`http://localhost:3000` (اولین ورود: ساخت کاربر مدیر)
- DNS روی IP همین دستگاه: پورت 53 و DoT روی 853
- پروکسی: پورت 2080 با کاربر `ofogh` (رمز در خروجی نصب چاپ می‌شود)
- حذف: `.\uninstall.ps1`

## تفاوت با نسخهٔ لینوکس (صادقانه)

- پنل مدیریت فارسی افق امن و تونل سروری WireGuard با NAT فعلاً نسخهٔ لینوکسی‌اند؛ روی ویندوز داشبورد AdGuard Home مدیریت DNS را می‌دهد و برای تونل کلاینت، اپ رسمی WireGuard کانفیگ‌های نودها را می‌گیرد.
- مش (اتصال نودها) روی ویندوز در حالت اندازه‌گیری و گزارش کار می‌کند؛ زنجیره‌کردن خروجی فعلاً لینوکسی است.
