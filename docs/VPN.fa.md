# VPN روی نود — L2TP/IPsec و PPTP

از نسخهٔ ۱٫۳ هر نود، علاوه بر تونل WireGuard، دو سرور VPN کلاسیک هم دارد:

- **L2TP/IPsec** (strongSwan + xl2tpd + ppp) — احراز هویت با کلید مشترک (PSK)
- **PPTP** (pptpd + ppp) — با رمزنگاری اجباری MPPE-128

دلیلش ساده است: **همهٔ دستگاه‌ها WireGuard ندارند.** ویندوز، اندروید، آیفون و تقریباً همهٔ روترها L2TP/IPsec را به‌صورت بومی می‌شناسند و برای وصل‌شدن هیچ اپی لازم ندارند؛ PPTP هم برای دستگاه‌های قدیمی‌ای است که هیچ‌کدام را ندارند. مسیر ترافیک دقیقاً مثل تونل WireGuard است:

```
دستگاه ← تونل VPN ← نود تو (DNS + NAT) ← سرور بازی / اینترنت
```

یعنی DNS کلاینت VPN هم همان SmartDNS نود است (از داخل تونل با آدرس داخلی نود داده می‌شود) و خروجی‌اش از همان سرور خارجی می‌رود.

## پورت‌ها

| سرویس | پورت / پروتکل | توضیح |
|---|---|---|
| IKE (IPsec) | UDP 500 | مذاکرهٔ کلید |
| IPsec NAT-T | UDP 4500 | وقتی کلاینت پشت NAT است |
| ESP | پروتکل IP ‏۵۰ | ترافیک رمزنگاری‌شدهٔ IPsec |
| L2TP | UDP 1701 | فقط داخل تونل IPsec معنا دارد |
| PPTP | TCP 1723 | کانال کنترل |
| GRE | پروتکل IP ‏۴۷ | ترافیک دادهٔ PPTP |

نصاب این پورت‌ها را در اسکریپت فایروال پروژه (`ofogheamn-firewall`) باز می‌کند و اگر ufw از قبل فعال باشد، آن‌جا هم بازشان می‌کند. اگر جلوی سرورت فایروال ابری (پنل VPS) داری، همین جدول را آن‌جا هم باز کن — مخصوصاً ESP و GRE که «پورت» نیستند و در بعضی پنل‌ها جدا باید اجازه داده شوند.

## اطلاعات اتصال

همهٔ اطلاعات اتصال در **یک فایل** است: `/etc/ofogheamn-dns/vpn.conf` — و در پنل وب، تب «VPN»، هم دیده می‌شود.

| | پیش‌فرض |
|---|---|
| نام کاربری | `ofogh` |
| رمز | `ofogh1234` |
| کلید IPsec (PSK) | `ofogheamn` |
| بازهٔ آدرس L2TP | `10.67.0.0/24` |
| بازهٔ آدرس PPTP | `10.68.0.0/24` |

> ### ⚠️ هشدار جدی: پیش‌فرض‌ها را عوض کن
> این مقادیر در مخزن عمومی پروژه چاپ شده‌اند و **هر کسی می‌داندشان**. نودی که با پیش‌فرض بالا بیاید، VPN عمومیِ هر غریبه‌ای است. قبل از این‌که آدرس نود را به کسی بدهی:
>
> ```sh
> ofogheamn-dns vpn set-user ali pass-قوی-خودت
> ofogheamn-dns vpn set-psk  یک-عبارت-طولانی-و-تصادفی
> ```
>
> (تغییر رمز به‌تنهایی: `ofogheamn-dns vpn set-pass <new>`) — بعد از هر تغییر، سرویس VPN خودش ری‌استارت می‌شود و فایل‌های chap-secrets و ipsec.secrets از روی vpn.conf دوباره ساخته می‌شوند؛ آن دو فایل را دستی ویرایش نکن.

## وصل‌شدن از ویندوز (L2TP/IPsec)

1. Settings ← Network & internet ← VPN ← Add VPN
2. VPN provider: **Windows (built-in)**
3. Server address: آی‌پی یا دامنهٔ نود
4. VPN type: **L2TP/IPsec with pre-shared key** — کلید: همان PSK نودت
5. نام کاربری و رمز VPN را بده و Connect.

نکتهٔ معروف ویندوز: اگر نود پشت NAT است (بیشتر VPSها نیستند)، ممکن است لازم شود رجیستری `AssumeUDPEncapsulationContextOnSendRule` را ۲ بگذاری؛ روی VPS با آی‌پی عمومی مستقیم، لازم نیست.

## وصل‌شدن از ویندوز (PPTP — فقط اگر مجبور شدی)

همان مسیر بالا، با VPN type = **Point to Point Tunneling Protocol (PPTP)** و همان نام کاربری و رمز. در Properties اتصال، رمزنگاری را روی **Require encryption** بگذار (سرور هم MPPE را اجباری کرده و اتصال بدون رمزنگاری را رد می‌کند).

## وصل‌شدن از اندروید

اندرویدهای قدیمی (تا Android 11) در Settings ← Network ← VPN هر دو را بومی دارند:

- **L2TP/IPsec PSK**: آدرس سرور + PSK + نام کاربری و رمز.
- **PPTP**: آدرس سرور + نام کاربری و رمز + تیک **PPP encryption (MPPE)** روشن.

از Android 12 به بعد گوگل PPTP و L2TP را از رابط کاربری حذف کرده است؛ روی گوشی‌های جدید از WireGuard یا پروکسی همین نود استفاده کن.

## آیفون و مک

- **iOS / macOS**: فقط **L2TP** (در تنظیمات VPN، نوع L2TP over IPsec) با همان PSK و نام کاربری/رمز. اپل PPTP را از iOS 10 حذف کرده است — برای آیفونِ خیلی قدیمی هم دیگر راهی نیست.
- مسیر مک: System Settings ← VPN ← Add VPN Configuration ← L2TP over IPsec.

## وصل‌شدن از روتر (کل خانه، از جمله کنسول)

بیشتر روترها (MikroTik، Keenetic، بعضی ایسوس‌ها و OpenWrt با پکیج xl2tpd) **کلاینت L2TP** دارند:

- MikroTik: ‏Interfaces ← + ← L2TP Client ← Connect To = آی‌پی نود، User/Pass = همان‌ها، و **Use IPsec** را روشن و IPsec Secret را همان PSK بگذار. بعد یک NAT masquerade روی اینترفیس l2tp-out و مسیر پیش‌فرض از همان.
- با این کار PS5 و بقیهٔ دستگاه‌های خانه بدون هیچ تنظیمی از نود رد می‌شوند — همان کاری که تونل WireGuard روی روتر می‌کند، برای روترهایی که WireGuard ندارند.

## صداقت امنیتی

- **PPTP ضعیف است.** رمزنگاری MS-CHAPv2/MPPE از نظر رمزنگاری شکسته محسوب می‌شود و مهاجم مصمم می‌تواند ترافیک ضبط‌شده را باز کند. PPTP این‌جا فقط برای دستگاه قدیمی‌ای است که هیچ راه دیگری ندارد؛ هر جا L2TP/IPsec می‌شود، همان را بزن. برای مسیرهای حساس، WireGuard همین پروژه انتخاب درست است.
- **L2TP/IPsec با PSK** یعنی هر کس PSK را بداند، می‌تواند خودش را جای سرور جا بزند؛ PSK را مثل رمز نگه دار و دوره‌ای عوضش کن.
- هر دو پروتکل ترافیک را از نود رد می‌کنند؛ نود می‌تواند DNS و مقصد اتصال‌ها را ببیند — مثل هر VPN دیگری، فقط به نودی وصل شو که به صاحبش اعتماد داری.

## مدیریت

```sh
ofogheamn-dns vpn status     # وضعیت + اطلاعات اتصال
ofogheamn-dns vpn restart
ofogheamn-dns health         # وضعیت VPN هم در گزارش سلامت می‌آید
systemctl status ofogheamn-vpn strongswan-starter xl2tpd pptpd
journalctl -u xl2tpd -u pptpd -f   # لاگ اتصال‌ها
```
