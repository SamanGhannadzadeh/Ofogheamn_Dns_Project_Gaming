# چک‌لیست اپراتور نود — Ofogheamn DNS

برای کسی که یک نود عمومی یا خصوصی بالا آورده و می‌خواهد سالم نگهش دارد.

## هر روز (خودکار)
- **سلامت:** تایمر `ofogheamn-health.timer` هر ۵ دقیقه نود را چک
  می‌کند؛ اگر DNS جواب ندهد، سرویس یک بار ری‌استارت می‌شود.
  دستی: `ofogheamn-dns health` — و در پنل، کارت‌های داشبورد.
- **گرم‌کن کش کالاف:** هر ۴ دقیقه (cod-warmup).
- **لیست مسدودی:** روزانه به‌روز می‌شود.

## هر هفته (۲ دقیقه)
- `ofogheamn-dns bench` — عددها را با هفتهٔ قبل مقایسه کن؛
  اگر DNS سرد خیلی بالا رفت، آپ‌استریم‌ها را بررسی کن.
- `ofogheamn-dns region` — اگر نود را جابه‌جا کردی یا ISP عوض شد،
  رتبه‌بندی منطقه و مشاورهٔ هر بازی را دوباره ببین.
- گواهی TLS: در خروجی health می‌آید؛ زیر ۱۴ روز یعنی وقت تمدید.

## پشتیبان
- ساخت: `ofogheamn-dns backup` → فایل فشرده در `/var/backups`
  (شامل کانفیگ، لیست‌ها، کلیدها و رمز پنل — محافظتش کن).
- برگرداندن: `ofogheamn-dns restore <file.tar.gz>`

## وقتی مشکلی شد
1. `ofogheamn-dns health` — اول ببین کدام بخش قرمز است.
2. `ofogheamn-dns logs dns 100` — خطای هسته.
3. ری‌استارت تمیز: `ofogheamn-dns restart`
4. نشد؟ بکاپِ سالمِ دیروز را restore کن.
