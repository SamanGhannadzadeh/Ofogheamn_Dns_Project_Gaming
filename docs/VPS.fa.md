# راهنمای انتخاب سرور (VPS) برای نود

رتبه‌بندی آمادهٔ فروشنده‌ها برای ایران قابل اعتماد نیست — منابع با
هم تناقض دارند و بیشترشان تبلیغاتی‌اند. این راهنما به‌جای اسم
بردن، **روش اندازه‌گیری** می‌دهد؛ با ابزار خود پروژه:

```
ofogheamn-dns region
```

روی نود اجرا می‌شود و پینگ دوسویهٔ نود تا منطقه‌های بازی را
رتبه‌بندی می‌کند.

## ترتیب شروع (از پژوهش مسیر ایران)

۱. **فرانکفورت اول.** تقریباً همهٔ ترانزیت بین‌الملل ایران در
   فرانکفورت فرود می‌آید و بیشتر سرورهای بازی اروپا هم همان‌جاست.
   کف واقع‌بینانه از تهران: ۷۰ تا ۱۱۰ میلی‌ثانیه (مشهد: +۱۰ تا ۲۰).
۲. **استانبول دوم** — روی نقشه نزدیک است، ولی باید با traceroute
   ثابت شود که مسیر دور نمی‌زند.
۳. **خلیج (بحرین/امارات) فقط با اثبات.** جغرافیا می‌گوید ۴۰ تا ۶۵
   میلی‌ثانیه، ولی اگر مسیر ترومبون شود (مثلاً از فرانکفورت رد
   شود) به ۹۰ تا ۱۳۰ می‌رسد — یک مسیر ۲۵۰ کیلومتریِ اندازه‌گیری‌شده
   به‌خاطر ترومبون ۱۷۵٫۹ میلی‌ثانیه بود.

## چک‌لیست قبل از خرید

- از خانه تا IP سرور traceroute بگیرید: اگر مسیر از فرانکفورت رد
  شد و برگشت، آن سرور «نزدیک» نیست، هر جا که باشد.
- روی خود سرور `ofogheamn-dns region` را اجرا کنید؛ رتبه‌بندی
  دوسویه ملاک نهایی است.
- پردازنده و رم برای این پروژه مهم نیستند؛ **کیفیت مسیر و
  پهنای باند پایدار** مهم است. ارزان‌ترین پلن معقول کافی است.
- IPv6 سالم و پورت‌های UDP باز (۵۳/۵۱۸۲۰) را همان روز اول چک
  کنید.
- ماهانه و قابل لغو بخرید تا اگر مسیر عوض شد، جابه‌جا شوید —
  مسیرهای ایران ثابت نمی‌مانند.
