# راهنمای گیمرها — استفاده از DNS عمومی افق امن

این پروژه برای **همهٔ گیمرهاست**: هر کسی می‌تواند یک نود عمومی راه بیندازد و هر گیمری می‌تواند به نزدیک‌ترین نود وصل شود. هرچه نود به تو نزدیک‌تر باشد، جواب DNS سریع‌تر می‌رسد و اتصال بازی تمیزتر شروع می‌شود.

> آدرس‌ها را از اپراتور نودت بگیر؛ نمونه‌ها: DNS ساده `X.X.X.X`، ‏DoT: ‏`dns.ofogheamn.ir`، ‏DoH: ‏`https://dns.ofogheamn.ir/dns-query`

## پلی‌استیشن ۵ (PS5)

1. Settings ← Network ← Settings ← Set Up Internet Connection
2. روی اتصالت Options ← Advanced Settings
3. DNS Settings ← Manual
4. Primary DNS = آدرس نود، Secondary = خالی یا همان آدرس
5. MTU: Automatic — OK

## ویندوز

Settings ← Network ← Wi-Fi/Ethernet ← DNS server assignment ← Edit ← Manual ← IPv4 On ← Preferred DNS = آدرس نود.
برای DoH رمزنگاری‌شده: اگر نودت DoH دارد، در همان بخش «DNS over HTTPS» را On کن و آدرس DoH را بده.

## اندروید

Settings ← Network ← Private DNS ← نام هاست نود (مثل `dns.ofogheamn.ir`) ← Save. (این همان DoT است و روی همهٔ برنامه‌ها اعمال می‌شود.)

## آیفون

Settings ← Wi-Fi ← (i) ← Configure DNS ← Manual ← آدرس نود را اضافه و بقیه را حذف کن.

## روتر خانه (بهترین گزینه — همهٔ دستگاه‌ها با هم)

در پنل روتر، DNS بخش DHCP/WAN را آدرس نود بگذار؛ PS5 و PC و موبایل همه خودکار از همان می‌گیرند.

## تونل گیمینگ (اختیاری، برای وقتی مسیر ISP بد است)

اگر اپراتور نودت تونل WireGuard می‌دهد: اپ WireGuard را نصب کن، کانفیگی که می‌گیری را Import کن و روشنش کن. حالا هم DNS و هم ترافیک بازی از نود رد می‌شود. برای PS5: تونل را روی روتر خانه ببند (روترهای OpenWrt/MikroTik WireGuard دارند).

## از کجا بفهمم بهتر شد؟

- منوی خود بازی (مثل وارزون) پینگ را نشان می‌دهد؛ قبل و بعد را همان‌جا مقایسه کن.
- چیزی که DNS بهتر می‌کند: سرعت وصل‌شدن و پیدا کردن سرور، پایداری اتصال، و لود سریع‌تر لابی و استور.
- چیزی که هیچ DNSای نمی‌تواند: اگر وسط بازی پینگت بالاست و مسیر اینترنتت تا سرور بازی ذاتاً دور است، فقط نزدیکی فیزیکی سرور بازی یا یک مسیر بهتر (تونل از یک نود نزدیک) کمک می‌کند — ادعاهای «کاهش پینگ جادویی» را باور نکن.

## خودت نود راه بینداز

اگر سرور داری، با یک دستور (README پروژه) نود شهر خودت را بالا بیاور تا گیمرهای نزدیکت پینگ بهتری بگیرند.
