# گیت‌وی کنسول — تنها راهِ رد شدنِ ترافیک بازی پلی‌استیشن از نود

## چرا کنسول به گیت‌وی نیاز دارد

پلی‌استیشن ۵ **تنظیم ساکس۵ ندارد**. تنها تنظیم پروکسیِ خود کنسول
یک پروکسی HTTP است: نه احراز هویت دارد، نه هیچ‌وقت ترافیک UDP
بازی را رد می‌کند — فقط ترافیک وبِ خود کنسول (استور، PSN،
دانلودها) از آن می‌گذرد. پورت‌های «mixed» این پروژه روی نود هم
SOCKS5 و هم HTTP می‌فهمند، برای همین همان فیلد HTTP کنسول با
نود کار می‌کند؛ ولی بازی، نه.

پس برای اینکه ترافیک واقعی بازی (UDP) به نود برسد، باید یک
دستگاه **سر راه** کنسول باشد و گیت‌وی او شود. همهٔ بوسترهای
تجاری هم دقیقاً همین کار را می‌کنند: GearUP جعبهٔ HYPEREV و
LagoFast جعبهٔ جدا می‌فروشند؛ پینگیوم برای کنسول فقط حالت DNS
دارد. این پروژه همان الگو را با یک جعبهٔ لینوکسی ارزان و
sing-box پیاده می‌کند.

## توپولوژی

```
PS5 ──Ethernet──► جعبهٔ گیت‌وی (لینوکس + sing-box) ──► مودم/روتر خانه ──► نود
```

جعبه می‌تواند یک مینی‌پی‌سی، لپ‌تاپ قدیمی، رزبری‌پای یا هر
لینوکسی با دو راه شبکه (کابل + وای‌فای هم می‌شود) باشد.

## راه‌اندازی

۱. روی نود، پروفایل را اجرا کنید تا `/root/ofogh-gateway.json`
ساخته شود (همراه بقیهٔ کانفیگ‌های مشتری).

۲. روی جعبهٔ گیت‌وی sing-box (نسخهٔ ۱٫۱۴) نصب کنید و فایل را
در `/etc/sing-box/config.json` بگذارید و سرویس را اجرا کنید.

۳. روی جعبه فوروارد را روشن کنید:

```
sysctl -w net.ipv4.ip_forward=1
sysctl -w net.ipv6.conf.all.forwarding=1
```

۴. به جعبه یک آی‌پی ثابت در شبکهٔ خانه بدهید (مثلاً
192.168.1.2) و در تنظیمات شبکهٔ پلی‌استیشن، حالت دستی:

- IP Address: یک آی‌پی آزاد (مثلاً 192.168.1.50)
- Subnet Mask: 255.255.255.0
- Default Gateway: آی‌پی جعبه (192.168.1.2)
- Primary DNS: آی‌پی جعبه (192.168.1.2) — DNS شبکهٔ محلی را
  خود گیت‌وی به رزولور نود می‌رساند (hijack-dns)

۵. تمام. همهٔ ترافیک کنسول — TCP و UDP، همهٔ پورت‌ها، IPv4 و
IPv6 — از تونل خودترمیمِ نود (Gecko ← Hysteria2 ← REALITY)
می‌گذرد و هیچ مسیری دورش نمی‌زند (strict_route).

## نکته‌ها

- MTU تونل ۱۲۸۰ است: کفِ امن برای مسیرهای PPPoE و موبایل
  ایران؛ اگر روی خط ثابت‌تان مطمئنید سیاه‌چاله ندارید، تا
  ۱۴۰۰ می‌شود بالا برد و تست کرد.
- اگر جعبه خاموش شود، کنسول اینترنت ندارد — عمدی است: نشتی
  دور تونل بدتر از قطعیِ معلوم است.
- برای گوشی و کامپیوتر نیازی به جعبه نیست؛ همان
  `ofogh-client.json` با اپ sing-box کافی است.
