# هایجک Smart DNS — چطور کار می‌کند

هایجک در این پروژه یعنی: برای **دامنه‌های مشخصی که خودت فهرست می‌کنی**، نود به‌جای آپ‌استریم، آی‌پیِ نقطهٔ خروجیِ خودت (ریله/آنلاک‌نود) را جواب می‌دهد تا ترافیک آن سرویس از جایی رد شود که تو انتخاب می‌کنی. فقط همان دامنه‌ها؛ بقیهٔ اینترنت عادی حل می‌شود.

## فرمان‌ها

```sh
# یک دامنه
ofogheamn-dns add-hijack api.example.com 203.0.113.10

# با آی‌پی نسخهٔ ۶ واقعیِ نقطهٔ خروجی
ofogheamn-dns add-hijack api.example.com 203.0.113.10 2001:db8::10

# کل فهرست دامنه‌های یک سرویس، با یک ریله (هر خط یک دامنه)
ofogheamn-dns add-hijack --file domains.txt 203.0.113.10

ofogheamn-dns list-hijack
ofogheamn-dns remove-hijack api.example.com
```

## قانون دوستونی (از نسخهٔ ۱٫۹)

هر قانون هایجک **دو خط** است: جواب A و جواب AAAA. اگر خط AAAA نباشد، کوئری‌های نسخهٔ ۶ از آپ‌استریم جواب واقعی می‌گیرند و کلاینت دوستونی (موبایل، ویندوز، کنسول) از کنار قانون رد می‌شود — هایجک عملاً سوراخ است.

برای همین `add-hijack` وقتی آی‌پی نسخهٔ ۶ نمی‌دهی، AAAA را با `::` جواب می‌دهد: پاسخ محلی و فوری، ولی غیرقابل‌مسیریابی؛ یعنی مسیر نسخهٔ ۶ بسته می‌شود و کلاینت روی همان آی‌پی نسخهٔ ۴ می‌ماند. اگر نقطهٔ خروجی‌ات آی‌پی نسخهٔ ۶ واقعی دارد، همان را بده تا هر دو ستون به ریله برسند.

## نکته‌ها

- قانون روی دامنه و همهٔ زیردامنه‌هایش اعمال می‌شود.
- فایل قوانین: `/etc/ofogheamn-dns/hijack.conf` — با دست هم می‌توانی ویرایشش کنی؛ بعدش `ofogheamn-dns restart`.
- نقطهٔ خروجی باید واقعاً ترافیک آن سرویس را رد کند (پروکسی یا تونل روی همان آی‌پی)؛ DNS فقط مسیر را نشان می‌دهد.
